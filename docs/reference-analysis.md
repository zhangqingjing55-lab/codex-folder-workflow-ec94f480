# 参考分析与改编

参考片段：[astra-motion](https://motionface.cc/?recording=ec94f480-6905-44ad-918b-fd4da19c5a25)。本地核查：30 秒、3840 × 2160、60 fps。原视频、音轨和签名下载地址不包含在仓库内。

## 观察

- 画面是浅色剪辑软件框架与深蓝预览区的组合，蓝色小人跨界面搬运和操作素材。
- 字体视觉上接近圆润黑体，标签和气泡较粗；仅从画面无法可靠确认具体字体。
- 色彩重心是蓝色角色、灰白软件面板，以及黄色操作提示。
- 约 0–5 秒：建立编辑器，角色与素材落位；约 5–13 秒：小人操作剪辑、特效和文字；约 13–23 秒：拉伸、跳跃、抛接，画面局部推近；约 23–30 秒：收束到成品展示。
- 主要节奏由预备姿势、快速动作、落地回弹与短暂停顿组成。转场靠角色移动、素材进入和画面推移完成。
